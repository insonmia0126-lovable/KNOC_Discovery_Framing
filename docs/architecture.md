# 구조

단일 PC에서 한 번에 실행하려고 Next.js 한 프로세스에 화면, API, 추출 작업, SQLite를 두었습니다. 지시한 `frontend/ backend/ workers/` 디렉터리를 프로세스 밖으로 나누면 로컬 실행이 두 명령이 됩니다. 책임은 코드에서 나뉩니다.

| 경로 | 책임 |
|---|---|
| `src/app` | 화면과 Route Handler |
| `src/server` | 인수인계, 검색, 저장, 추출 |
| `src/providers` | 생성 모델 연결. 데모 규칙과 분리 |
| `sample-data` | 합성 자료와 평가 질문 |
| `private-data` | 업로드 원본 복사, SQLite, Git 제외 |
| `config` | 기관·모델 예시. 키 없음 |

저장소 루트에는 기존 자세 코칭 과제가 있어 이 앱은 `knoc-discovery-framing/`에 두었습니다. 그 과제 파일은 수정하지 않았습니다.

임베딩 색인은 연결하지 않았습니다. 검색 점수는 토큰 포함 길이 합이며 확률이 아닙니다. HWP, OCR, DOCX, 실시간 시황은 구현하지 않았습니다.

작업 큐는 `index_jobs`에 남고, 서버 계측에서 짧은 간격으로 다시 집습니다. 실패 파일은 다음 파일을 막지 않습니다. 같은 파일명과 해시가 다시 오면 문서를 중복 생성하지 않습니다. 내용이 같고 이름이 다른 복제본은 중복 검사용으로 두 줄이 됩니다.

원본 샘플 파일은 읽기만 하고, 처리본은 `private-data/originals`에 복사합니다.
