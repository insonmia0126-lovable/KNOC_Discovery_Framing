# KNOC Discovery & Framing

석유정보 분석 경험을 다음 담당자에게 넘기는 업무바통입니다. 등록한 보고서에서 과거 유사 문장을 찾고, 전임자가 판단과 남은 업무를 고쳐 확정하면, 후임자가 그 버전을 인수합니다.

이 폴더의 샘플은 **가상 시나리오·합성 자료**입니다. 페트로넷 원문이 아니고, 약 6,000개 PDF 전체 처리 검증은 **미실시**입니다.

상위 저장소에는 별도 과제(자세 코칭)가 있어 이 앱만 `knoc-discovery-framing`에 두었습니다.

## 선택한 구성

| 구성 | 확인한 버전 | 이유 |
|---|---|---|
| Node.js | 22.23.4 | 이 환경의 런타임 |
| Next.js | 15.5.15 | 화면과 API를 한 프로세스로 실행 |
| React | 19.1.0 | Next.js 템플릿 |
| better-sqlite3 | 13.x | 재시작 뒤에도 남는 로컬 DB. 외부 DB 없음 |
| pdfjs-dist | 6.5.438 | PDF 페이지 텍스트 |
| pdf-lib, @pdf-lib/fontkit | 1.17.1 / 1.1.1 | 합성 PDF 생성 |
| xlsx | 0.18.5 | 일정표 |
| zod | 4.x | 실제 모델 JSON 검사 |

임베딩, OCR, HWP, DOCX, 실시간 시황, SSO는 넣지 않았습니다. 설정 화면에 미지원으로 적혀 있습니다.

## 실행

네트워크가 필요한 단계: `npm install`, 글꼴 파일이 없을 때 `npm run generate-samples`, 실제 모델 호출.

오프라인으로 가능한 단계: 설치와 샘플 생성이 끝난 뒤의 데모 모드 검색·확정·인수. 데모는 기기 안 AI가 아닙니다. 미리 둔 규칙입니다.

```bash
cd knoc-discovery-framing
npm install
npm run generate-samples
npm test
npm run dev
```

브라우저에서 `http://127.0.0.1:3847` 을 엽니다. 개발 서버는 미리보기 때문에 `0.0.0.0:3847`에 붙습니다. 같은 PC만 쓰려면 방화벽으로 막으세요. 인증이 없는 단일 PC 데모입니다.

종료: 서버를 실행한 터미널에서 Ctrl+C.

생산 실행:

```bash
npm run build
npm start
```

환경변수는 `.env.example`을 복사합니다. `LLM_API_KEY`가 없어도 데모는 됩니다. 설정에서 실제 모델을 고르면 키가 없을 때 오류가 나고, 데모 문장으로 바꾸지 않습니다.

Windows에서 같은 명령을 쓰는 절차는 이 리눅스 환경에서 시험하지 않았습니다.

## 쓰는 순서

1. 자료실에서 **합성 자료 등록**.
2. 새 인수인계에서 기준일을 적고 저장합니다. 예시 기준일은 2024-03-18입니다.
3. 당시 판단 또는 사후 평가를 고르고 유사 사례와 초안을 만듭니다.
4. 오른쪽 발췌를 보고 전임자 역할로 고친 뒤 **전임자 확정**.
5. 데모 역할을 후임자로 바꾸고 **후임자 인수 확인**.
6. Markdown, JSON, 인쇄로 내보냅니다.

역할 선택은 로그인이 아닙니다. 서버는 요청 헤더의 데모 역할만 검사합니다. 읽기 역할은 확정이 거절됩니다.

## 데이터

처리 복사본과 SQLite는 `private-data/`에 생기며 Git에 넣지 않습니다. 샘플 원본은 `sample-data/files`에 있고 처리 중 내용을 바꾸지 않습니다.
